## Critical Issues (Fix Immediately)

1. **5 unused dependencies** inflating `node_modules` and potential attack surface — `@google/genai`, `express`, `dotenv`, `esbuild`, `tsx`
2. **No `prefers-reduced-motion`** — violates WCAG 2.3.3, causes vestibular disorders for sensitive users
3. **No `<main>` landmark** — WCAG 2.4.1 bypass blocks failure
4. **Missing `og:image`** — social sharing shows no preview image, devastating for marketing
5. **Logo.png at 2MB** — loaded nowhere in the app but committed to repo; `logo.ico` at 238KB is 10x larger than a typical ICO

---

## High Priority Issues (Fix This Sprint)

6. WhatsApp number hardcoded in 3 locations — single source of truth violated
7. CSS classes `custom-scrollbar` and `scrollbar-hide` used but never defined
8. Customer count data inconsistency between About and Stats sections
9. TypeScript `strict` mode disabled
10. No Error Boundary — entire app crashes on any component error

## What's Working Well

- Strong visual identity with consistent gold/dark color palette
- Good use of Motion library for scroll-linked parallax animations
- Lazy loading via `React.lazy` and `Suspense` for below-the-fold sections
- Clean component separation — each section is its own component
- Data files properly externalized (`config.ts`, `services.ts`, `stats.ts`, `testimonials.ts`)
- Custom hook for order calculator logic (`useOrderCalculator.ts`)
- WhatsApp integration is well-implemented with pre-filled messages
- RTL layout correctly configured in `<html lang="ar" dir="rtl">`
- JSON-LD structured data present for local business SEO
- GitHub Actions CI/CD pipeline properly configured
